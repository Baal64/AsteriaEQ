# ADR-0004 - Absolute Axis Position Using AS5048A Encoders

- **Status:** Accepted
- **Date:** 2026-08-05
- **Decider:** Alexandre Ba

---

## Context

Asteria EQ requires accurate knowledge of the Right Ascension (RA) and
Declination (DEC) axis positions.

Several approaches were considered:

- incremental encoders with homing sensors;
- Hall-effect reference sensors;
- absolute magnetic encoders.

The project requires:

- immediate knowledge of the axis position after power-up;
- no mandatory homing sequence;
- low hardware complexity;
- high angular resolution.

---

## Decision

Each axis uses one AS5048A absolute magnetic encoder connected through the
hardware SPI bus.

The two encoders share the SPI bus and are individually selected using
dedicated Chip Select (CS) signals.

No Hall-effect reference sensors are required in the initial hardware
architecture.

The AS5048A becomes the unique reference for axis position.

---

## Consequences

### Positive

- Absolute position available immediately after startup.
- No homing sequence required.
- Reduced hardware complexity.
- Fewer sensors and wiring.
- High angular resolution.
- Simplified initialization procedure.

### Negative

- Correct mechanical calibration of the encoder offset is required.
- Loss of the encoder results in loss of absolute position information.
- Encoder calibration becomes part of the commissioning process.

---

## Alternatives Considered

### Hall-effect Reference Sensors

Hall sensors would provide a repeatable mechanical reference position.

**Advantages**

- Independent reference point.
- Useful for redundancy.

**Disadvantages**

- Additional sensors.
- Additional wiring.
- Homing sequence required after startup.
- Increased software complexity.

This option was rejected for the first hardware revision.

---

### Incremental Encoders

Incremental encoders require continuous counting and a reference procedure after
power-up.

This option was rejected because it increases firmware complexity while
providing no benefit over absolute encoders for this project.

---

## Impact on Architecture

The encoder abstraction remains independent from the motion controller.

The firmware always retrieves the current axis position through the encoder
interface.

The motion control algorithms are independent from the underlying encoder
technology.

No homing subsystem is required in the Core layer.

## Notes

Hall-effect sensors may be added in a future hardware revision as an optional
redundant reference or diagnostic feature.

Their addition does not modify the Core architecture.

## Design principle

The mount always knows where it is.

Absolute position is considered the nominal operating mode.

Reference sensors are optional diagnostic devices rather than mandatory
position references.
