
1. Une classe possède une seule responsabilité.

2. Une information n'a qu'un seul propriétaire.

3. Les composants communiquent via des objets métier.

4. Le matériel ne remonte jamais dans le métier.

5. Les allocations dynamiques sont interdites dans le cœur du firmware.

6. Les dépendances sont injectées, jamais créées en interne.

7. Une abstraction n'est créée que lorsqu'elle émerge naturellement.
