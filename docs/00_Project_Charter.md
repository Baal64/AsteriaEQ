# Asteria EQ

## Mission

Concevoir une monture équatoriale performante,
fiable et totalement maîtrisée.

---

## Vision

Construire un firmware évolutif,
documenté et indépendant du matériel.

---

## Valeurs

- Architecture avant implémentation.
- Documentation vivante.
- Code lisible.
- Évolutivité.
- Robustesse.
- Simplicité.
- Compréhension du système avant optimisation.
- Le code est la conséquence de l'architecture, pas son point de départ.
